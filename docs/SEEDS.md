# Design Seeds

This project was built from creative prompts batched in Claude Desktop and
implemented by Claude Code. These are the original seed documents, preserved
as a record of the design process.

| # | Seed | What it prompted |
|---|------|-----------------|
| 1 | [Game concept](seeds/01-game-concept.md) | Core premise, learning model, phase system, L1 content, characters |
| 2 | [Skin system + Ethiopia](seeds/02-skin-system-ethiopia.md) | Multi-skin architecture, Ethiopia skin direction |
| 3 | [Ethiopia content](seeds/03-ethiopia-content.md) | All 4 Ethiopia levels, characters, pedagogy notes |
| 4 | [Sprite reference](seeds/04-sprite-reference.md) | Pixel art specs for both skins (palettes, dimensions, descriptions) |

The `seeds/` directory also contains `sacred_coffee_bean_fixed.svg`, an SVG
asset delivered with the Ethiopia seed. The game uses canvas pixel art at
runtime, not SVGs — this is preserved as a design reference.

Each file in `seeds/` is the original prompt as delivered — unedited.
